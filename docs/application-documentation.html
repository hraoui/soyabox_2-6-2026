📋 Vue d'ensemble

L'application POS (Point de Vente) est un système complet de gestion de restaurant développé en Flutter. Elle permet la gestion des commandes, des tables, des utilisateurs, des produits et des livraisons avec une interface moderne en glassmorphism.

🎯 Objectifs principaux

💳 Encaissement rapide

Interface POS sécurisée pour traiter les commandes clients rapidement et efficacement.

👥 Gestion multi-utilisateurs

Système de rôles (admin, staff, livreur) avec authentification par mot de passe et PIN.

🍽️ Gestion des tables

Plan de salle interactif pour suivre l'occupation des tables en temps réel.

📦 Catalogue produits

Gestion complète des produits et catégories avec synchronisation backend.

🚚 Livraisons

Suivi des livraisons et gestion des livreurs avec codes PIN dédiés.

🔄 Synchronisation

Sync automatique avec le backend API toutes les 15 secondes pour les commandes.

🗄️ Base de données (Isar)

L'application utilise Isar, une base de données NoSQL locale ultra-rapide pour Flutter, permettant le stockage offline et la synchronisation avec le backend.

🎮 Controllers - Actions détaillées

Les controllers utilisent le pattern GetX pour la gestion d'état et l'injection de dépendances.

🔐 AuthController auth_controller.dart

Gère l'authentification, les sessions et la sécurité des utilisateurs.

  • registerUser() async Inscrit un nouvel utilisateur avec email, téléphone, mot de passe, rôle et PIN
  • loginUser(identifier, password) async Connecte un utilisateur (online puis fallback local)
  • logout() async Déconnecte l'utilisateur et clear la session
  • changePassword(oldPassword, newPassword) async Change le mot de passe de l'utilisateur connecté
  • updateUserProfile() async Met à jour le profil (nom, téléphone, email, PIN)
  • isValidPin(pin) Valide le format du code PIN (4-6 chiffres)

💳 PosController pos_controller.dart

Gère l'interface de point de vente, le panier et les commandes.

  • unlockWithPin(pin) async Déverrouille le POS avec le code PIN du staff
  • lock() Verrouille le POS et clear l'état
  • setFulfillmentType(type) Définit le type: on_site, pickup, delivery
  • setTableNumber(number) Définit le numéro de table pour sur place
  • setCustomerInfo() Définit nom, téléphone et adresse du client
  • addToCart(product) Ajoute un produit au panier
  • removeFromCart(product) Retire un produit du panier
  • setCartItemQuantity(product, quantity) Modifie la quantité d'un produit
  • createOrder() async Crée une nouvelle commande avec le panier actuel
  • loadOrdersToday() async Charge les commandes du jour avec filtrage par rôle
  • setSearchTerm(term) Définit le terme de recherche pour les produits
  • filterProductsBySearch(products) Filtre les produits par terme de recherche
  • ensureTables() async Charge les tables depuis la base de données

📦 ProductController product_controller.dart

Gère le catalogue des produits et leurs opérations CRUD.

  • fetchAllProducts() async Récupère tous les produits depuis la base
  • createProduct() async Crée un nouveau produit avec nom, prix, catégorie, image
  • updateProduct() async Met à jour les informations d'un produit
  • deleteProduct(productId) async Supprime un produit de la base
  • getProductsByCategory(categoryId) Retourne les produits d'une catégorie (disponibles uniquement)
  • getAvailableProducts() Retourne tous les produits disponibles
  • getProductsOnOffer() Retourne les produits en promotion

🏷️ CategoryController category_controller.dart

Gère les catégories de produits.

  • fetchAllCategories() async Récupère toutes les catégories
  • createCategory(name, image) async Crée une nouvelle catégorie
  • updateCategory() async Met à jour une catégorie existante
  • deleteCategory(categoryId) async Supprime logiquement une catégorie (soft delete)
  • selectCategory(category) Sélectionne une catégorie active
  • getActiveCategories() Retourne les catégories non supprimées

👥 UserController user_controller.dart

Gère les utilisateurs et leurs permissions.

  • fetchAllUsers(restaurantId) async Récupère les utilisateurs filtrés par restaurant
  • createUser() async Crée un utilisateur via API (avec PIN auto-généré)
  • updateUser() async Met à jour les informations d'un utilisateur
  • toggleUserActivation(userId) async Active/désactive un compte utilisateur
  • deleteUser(userId) async Supprime un utilisateur
  • syncStaffFromBackend() async Synchronise le personnel depuis le backend
  • getUsersByRole(role) Filtre les utilisateurs par rôle
  • getActiveUsers() / getInactiveUsers() Filtre par statut d'activation

🏪 RestaurantController restaurant_controller.dart

Gère les restaurants et leurs configurations.

  • fetchAllRestaurants() async Récupère les restaurants (filtré par admin connecté)
  • createRestaurant() async Crée un nouveau restaurant
  • updateRestaurant() async Met à jour les informations d'un restaurant
  • toggleRestaurantActivation() async Active/désactive un restaurant
  • deleteRestaurant() async Supprime un restaurant
  • setSelectedRestaurantId(id) Sélectionne un restaurant actif

🪑 TableController table_controller.dart

Gère les tables du restaurant et leur positionnement.

  • loadTables(restaurantId) async Charge les tables depuis la base
  • importTables(restaurantId) async Importe les tables depuis le backend API
  • createTable() async Crée une table avec position grid (column/row start/end)
  • updateTable() async Met à jour une table existante
  • deleteTable(table) async Supprime une table
  • changeStatus(table, status) async Change le statut d'une table (libre, occupée, etc.)

🚚 DeliveryController delivery_controller.dart

Gère les livreurs et les commandes en livraison.

  • fetchDeliveriesByRestaurant(restaurantId) async Récupère les livreurs d'un restaurant (API + local)
  • createDelivery() async Crée un livreur avec validation téléphone (10 chiffres)
  • updateDelivery() async Met à jour les informations d'un livreur
  • toggleDeliveryActivation(deliveryId) async Active/désactive un livreur
  • deleteDelivery(deliveryId) async Supprime un livreur
  • syncLocalDeliveriesToBackend() async Synchronise les livreurs locaux vers le backend

📥 ImportController import_controller.dart

Gère l'import des données depuis le backend API.

  • importAllData() async Importe toutes les données (restaurants, tables, catégories, produits, utilisateurs, livreurs)
  • importCategories() async Importe les catégories depuis le backend
  • importProducts() async Importe les produits et queue les commandes non synchronisées
  • importRestaurants() async Importe les restaurants filtrés par admin
  • importTables(restaurantId) async Importe les tables d'un restaurant
  • importUsers() async Importe les utilisateurs d'un restaurant
  • importDeliveries() async Importe les livreurs d'un restaurant
  • updateBaseUrl(newBaseUrl) Met à jour l'URL de base de l'API
  • updateApiToken(token) Met à jour le token d'authentification API

🔄 SyncController sync_controller.dart

Gère la synchronisation automatique avec le backend.

  • syncNow() async Force une synchronisation immédiate
  • manualSync() async Synchronisation manuelle (admin seulement)
  • clearApiOrderRemoteState() async Clear le state API pour recréer les commandes
  • _tick() async private Exécuté toutes les 15 secondes pour auto-sync
  • _syncInternal() async private Logique interne de synchronisation (queue flush + pull API)

⚙️ SettingsController settings_controller.dart

Gère les paramètres de l'application.

  • load() async Charge les paramètres depuis le stockage local
  • updateCurrency(code, symbol) async Met à jour la devise (ex: EUR, €)
  • updateAppLogo(path) async Met à jour le logo de l'application
  • updateTicketLogo(path) async Met à jour le logo des tickets
  • uploadAppLogo(file) async Upload un nouveau logo depuis FilePicker
  • uploadTicketLogo(file) async Upload un nouveau logo de ticket
