Contexte — SOYABOX

SOYABOX est une application Flutter offline‑first avec base locale Isar, file d'attente de synchronisation et possibilité de déploiement self‑hosted. Supporte multi‑restaurants, réception de commandes depuis API/web/mobile et interface POS web/mobile pour le staff.

Détail coûts SOYABOX (indicatif)

  • Intégration & dev multi‑restaurants : 5 000€ – 40 000€ (API, gestion multi‑sites, web POS, mobile apps).
  • Hébergement : 20€ – 500€/mois (small → HA infra).
  • PSP frais : 0,9%–3,5% + 0,05–0,30€/tx.
  • Matériel par point : 300€ – 1 500€ (tablette/PC, imprimante, tiroir, lecteur CB).
  • Maintenance : 300€ – 2 500€/mois selon SLA.

Détail coûts POS commerciaux (indicatif)

  • Abonnement par site : 0€ – 300€/mois (selon plan/features).
  • Frais PSP/transaction : ~1% – 3% + fixe par tx (varie).
  • Matériel : 50€ – 1 500€ (hardware vendu/lu en pack).
  • Coûts cachés : intégrations, modules premium, frais de mise à l'échelle.

Usage & recommandation pratique

  • Choisir SOYABOX si : vous gérez plusieurs restaurants, avez des contraintes réseau, voulez contrôler les données et adapter le workflow métier (ex : intégrations locales livraison).
  • Choisir une solution commerciale si : vous privilégiez déploiement rapide, support inclus, intégrations paiements & matériel clés en main, et coûts prévisibles.
  • Pour un MVP multi‑restaurants avec tests terrain : SOYABOX permet validation offline & processus métiers avant arbitrage PSP/infra.
  • Si vous n'avez pas équipe dev ni budget d'intégration, une offre SaaS peut être plus rentable à court terme.

Checklist technique avant décision

  • Définir volumes estimés (transactions/jour par site) pour comparer coûts PSP et hébergement.
  • Valider capacité offline (durée sans réseau acceptable, files d'attente, conflits de sync).
  • Tester imprimantes/lecteurs CB sur toutes les plateformes ciblées (Windows/macOS/Android/iOS).
  • Évaluer nécessité d'intégrations externes (marketplaces, livreurs, compta) et complexité d'implémentation.
