🎯 Guide d'Utilisation du Système POS - Serveur

Ce guide vous explique pas à pas comment utiliser efficacement le système de point de vente (POS) en tant que serveur. Suivez ces instructions pour une expérience optimale et éviter les erreurs courantes.

🔐 Connexion au Système

Étape 1 : Accès au système

  1. Ouvrez l'application caisse sur votre terminal
  2. Sélectionnez votre rôle : Serveur
  3. Entrez votre code PIN personnel (4 à 6 chiffres)
  4. Confirmez votre identité avec votre badge si requis
💡 Astuce : Votre code PIN est confidentiel. Ne le partagez jamais avec vos collègues. En cas d'oubli, contactez immédiatement un administrateur.

🍽️ Création d'une Commande

Étape 2 : Démarrer une nouvelle commande

  1. Cliquez sur le bouton "Nouvelle Commande" ou appuyez sur la touche F1
  2. Sélectionnez le type de commande :
    • Sur place : Pour les clients assis en salle
    • À emporter : Pour les commandes à emporter
    • Livraison : Pour les commandes livrées
  3. Indiquez le numéro de table si applicable (sur place)
  4. Ajoutez les informations client si nécessaire (nom, téléphone)

Étape 3 : Ajouter des articles

  1. Naviguez dans les catégories (Entrées, Plats, Desserts, Boissons, etc.)
  2. Cliquez sur l'article souhaité
  3. Modifiez les options si disponibles (taille, ingrédients, préférences)
  4. Ajoutez des remarques spéciales (ex: "sans oignon", "bien cuit")
  5. Confirmez l'ajout à la commande

🔍 Recherche rapide

Utilisez la barre de recherche en haut pour trouver rapidement un article par son nom.

🔄 Modifications

Cliquez sur un article déjà ajouté pour le modifier, supprimer ou ajouter des remarques.

💳 Gestion du Paiement

Étape 4 : Finaliser la commande

  1. Vérifiez que tous les articles sont corrects
  2. Cliquez sur "Payer" en bas de l'écran
  3. Sélectionnez le mode de paiement :
    • Cash : Paiement en espèces
    • TPE : Paiement par carte bancaire
    • En compte : Paiement différé (clients fidèles)
  4. Entrez le montant reçu (pour le cash)
  5. Confirmez le paiement
⚠️ Attention : Une fois le paiement confirmé, la commande est envoyée en cuisine et ne peut plus être modifiée sans l'autorisation d'un administrateur.

📋 Fonctionnalités Avancées

Gestion des Tables

  • Fusionner des tables : Sélectionnez plusieurs tables et cliquez sur "Fusionner"
  • Déplacer une commande : Glissez-déposez une commande vers une autre table
  • Diviser l'addition : Cliquez sur "Diviser" pour séparer le paiement entre plusieurs clients

Gestion des Commandes Spéciales

  • Commandes rapides : Utilisez les raccourcis clavier pour les articles fréquents
  • Remises : Appliquez des remises avec l'autorisation d'un manager
  • Annulations : Annulez des articles avant l'envoi en cuisine

🖨️ Impression et Tickets

Impression des tickets

  1. Après paiement, le ticket s'imprime automatiquement
  2. Pour réimprimer : Cliquez sur l'historique et sélectionnez la commande
  3. Cliquez sur "Imprimer" dans le menu de la commande
  4. Choisissez entre aperçu ou impression directe

📊 Rapports et Historique

En tant que serveur, vous pouvez accéder à :

  • Vos commandes du jour : Historique de toutes vos ventes
  • Rapport journalier : Résumé de votre performance
  • Chiffre d'affaires : Total de vos ventes
  • Nombre de commandes : Statistiques par type

🚨 Dépannage Courant

Problème Solution
Erreur de connexion Vérifiez votre code PIN et contactez un admin si le problème persiste
Imprimante non connectée Le système affichera un aperçu à l'écran. Contactez le support technique.
Article introuvable Vérifiez la catégorie ou utilisez la recherche. L'article peut être désactivé.
Paiement refusé Vérifiez le montant et le mode de paiement. Pour les cartes, vérifiez le TPE.
Commande bloquée Contactez immédiatement un administrateur pour débloquer la commande.

📞 Support et Assistance

En cas de problème technique :

  • Ne redémarrez pas l'application sans sauvegarder vos commandes
  • Notez le numéro d'erreur exact si affiché
  • Contactez le support technique au XXX-XXXX-XXXX
  • Prévenez immédiatement votre manager

✅ Bonnes Pratiques

  • Toujours se déconnecter en fin de service
  • Vérifier les commandes avant de les envoyer en cuisine
  • Communiquer clairement les remarques spéciales
  • Maintenir la confidentialité des codes d'accès
  • Signaler rapidement tout dysfonctionnement
